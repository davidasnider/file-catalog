**Code Review Threads (Inline):**
- **copilot-pull-request-reviewer** on `src/scripts/inspect_file.py` line 567 (Unresolved):
> The previous predicate was a suffix match (`LIKE '%{escaped_path}'`), but `contains` matches the fragment anywhere, so an input such as `Appointments.txt` can also return `/archive/Appointments.txt.bak` or an unrelated directory match. This also passes the manually escaped value into `autoescape=True`, causing literal `%`, `_`, and backslash characters to be escaped twice. Remove the manual escaping and use `endswith(path, autoescape=True)` to preserve the original behavior.
>
> This issue also appears on line 579 of the same file.
- **copilot-pull-request-reviewer** on `src/scripts/invalidate_failed_tasks.py` line 54 (Unresolved):
> The filter is manually escaped before being passed to `contains(..., autoescape=True)`. `autoescape` escapes the raw value itself, so an `error_filter` containing `%`, `_`, or `\\` is double-escaped and no longer matches the actual error text. Pass `error_filter` directly and remove the `escaped` transformation.
- **copilot-pull-request-reviewer** on `src/scripts/report_failures.py` line 137 (Unresolved):
> `ext_filter` is documented and applied above as an extension/suffix filter (`doc.path.lower().endswith(...)`), and the previous SQL predicate was `LIKE '%<filter>'`. `contains` now includes paths that merely contain `.pdf` (for example, `/a.pdf.backup`), so the summary counts can disagree with the filtered failures. Use `endswith` with `autoescape=True` here to preserve the suffix semantics.
- **copilot-pull-request-reviewer** on `test_sqla.py` line 9 (Unresolved):
> Because this new root-level file matches pytest's default `test_*.py` discovery, importing it registers a second `Document` table in the global `SQLModel.metadata`. The real `src.db.models.Document` is then imported by the suite and raises SQLAlchemy's duplicate-table error during collection (regardless of import order). Remove this scratch probe or make it use the production model in a proper test module.
